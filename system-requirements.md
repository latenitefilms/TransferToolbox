# System Requirements

Transfer Toolbox currently supports the following Final Cut Pro versions:

Mac Version | iPad Version
------------|----------------
v10.7       | v1.3
v10.7.1     | v1.3
v10.8       | v2.0
v11.0       | v2.1
v11.1.1     | v2.2.1
v11.2       | v2.3
v12.0       | v3.0
v12.3       | v3.4
v12.4       | v3.4

You can find Final Cut Pro for Mac's system requirements [here](https://support.apple.com/en-us/111903).
